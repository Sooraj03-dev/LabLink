# Design decisions

## Motion priority for the proposed visual polish

The visual polish brief takes precedence over P03 where their interaction guidance differs. The hero scope owns the continuous animation. The notebook owns the scroll sequence. Buttons use a 1px press and a short colour response. Resource tags swing only on interaction, and a confirmed action can use the LOGGED stamp. Reduced motion takes precedence throughout.

## Sample inventory and direct login

The updated catalogue brief adds illustrative unit counts and dates for the existing eight resources. Each quantity and the campus statistics are identified as sample data. The main login screen opens browser-local sample workspaces for the three roles. Campus Firestore actions still require a verified Firebase session, and review decisions require assignment to that individual reviewer.
